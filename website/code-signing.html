Code signing policy

Last updated 25 November 2026

Kumpas installers are not code-signed yet, so Windows and macOS show a warning the first time you open them. We plan to apply for free code signing for Windows from the SignPath Foundation.

What gets signed

  • Only installers built automatically by GitHub Actions from the public source code, for a tagged release. The build scripts are part of that source code.
  • Nothing built on a personal computer is ever signed.
  • Every signed release is approved by hand by a member of the team below.
  • Signed files carry the product name Kumpas and the release's version number.

Privacy

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it. The details are in the privacy policy.

What the installers change

  • Windows: an optional Windows Firewall rule (a checkbox, on by default) so phones on home and work networks can connect; public networks stay blocked. Starting with Windows is a separate checkbox, off by default. The uninstaller removes both.
  • Linux (.deb): a udev rule that lets the logged-in user send keyboard and mouse input through /dev/uinput, needed on Wayland. Removing the package removes it.
  • macOS: nothing outside the app. macOS asks you to allow Accessibility (and Screen Recording for the screen view).
