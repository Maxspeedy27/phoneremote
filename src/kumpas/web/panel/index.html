No internet? Connect without it
  1. Phone hotspot (easiest): turn on Hotspot on the phone (in the quick settings or Control Center), join its Wi-Fi from this laptop, then scan the code under Same Wi-Fi / no internet.
  2. USB cable: plug the phone into this laptop. Android: Settings → Hotspot & tethering → USB tethering. iPhone: Settings → Personal Hotspot → Allow Others to Join (Windows also needs Apple's Apple Devices app). Then scan the same code.
  3. Bluetooth: pair the phone in this laptop's Bluetooth settings and turn on Bluetooth tethering on the phone.

Kumpas notices these connections and puts the right address in the code.
